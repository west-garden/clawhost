User Portal — Page Structure

All pages the end user sees after login

Page Map
🔑 Auth (no login required)
/login — email/password + OAuth buttons (GitHub, Google)
/register — email + password + name
/forgot-password — reset via email
📊 Dashboard (login required)
/dashboard — Agent list (cards or table), quick stats
└ Each agent shows: name, status badge, slug, created time
└ Actions: Start / Stop / Open WebUI / Delete
└ "Create Agent" button → /agents/new
➕ Create Agent
/agents/new — form: name, slug (auto-gen), model provider + API key
└ Submit → calls POST /api/v1/agents → redirect to agent detail
🤖 Agent Detail
/agents/:id — tabbed layout:
├ Overview — status, endpoint, access token, quick actions
├ Config — model providers, agent defaults, raw config
├ Channels — Telegram/Slack/Discord/WeChat etc.
├ Skills — list / create / edit / delete
└ Devices — paired devices, approve/revoke
⚙️ User Settings
/settings — profile (name, email, avatar), change password, API token, OAuth connections
